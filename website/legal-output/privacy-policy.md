# Privacy policy

Last updated: 27 October 2026

This policy covers the sshbox website at https://sshbox.constlm.xyz. It does not cover independent sshbox servers run by other people. The site is operated by kknxzz, based in Romania. To get in touch, use the [sshbox GitHub issues page](https://github.com/kknxzz/sshbox/issues). Issues are public, so please do not post private information there; ask for a private way to contact the operator instead.

## What the website receives

When you visit, the web server may record request information such as your IP address, the date and time, the page requested, browser details, referrer, and response status. The exact fields depend on the server configuration. These records help serve the site, troubleshoot problems, and investigate abuse.

The website has no sign-up form or user accounts. If you open an issue on GitHub, GitHub and the operator can see the details you choose to provide there. The site's pages do not directly include an analytics script or set tracking cookies.

## Cloudflare and GitHub

Cloudflare may process network and request information to provide DNS, security, delivery, and domain-level traffic analytics, depending on the site's Cloudflare settings. The operator may see aggregate request and security statistics in the Cloudflare dashboard. This is separate from the optional Cloudflare Web Analytics browser beacon, which is not included in the site's source code. Cloudflare's own cookies or security features may depend on the settings in use. See [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/) and [Cloudflare's analytics documentation](https://developers.cloudflare.com/analytics/account-and-zone-analytics/zone-analytics/).

Your browser contacts GitHub's API to retrieve the latest release and star count. Download links take you to GitHub. GitHub receives those requests and handles them under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). If GitHub's API is unavailable, the site uses a bundled release snapshot.

## Why information is used and how long it is kept

The operator uses server request information to deliver and maintain the site, diagnose problems, and protect it from abuse. For visitors in the European Economic Area, the intended legal basis is the operator's legitimate interest in operating and securing the website, balanced against visitors' rights. Cloudflare and GitHub process information as described in their own notices.

Server logs are kept for the period needed for operation, troubleshooting, and security investigations. A fixed log-retention period has not yet been set; this policy will be updated when the server configuration is finalised. Provider retention periods depend on their services and settings.

## Your rights

Depending on where you live and the law that applies, you may have the right to ask for access to, correction or deletion of your personal data, to restrict or object to processing, or to receive data in a portable format. You can also complain to a data protection authority, including Romania's [ANSPDCP](https://www.dataprotection.ro/), or the authority where you live or work.

Use the GitHub issues page above to ask how to make a privacy request. Please do not include sensitive details in a public issue. The operator may need enough information to identify the relevant request data and respond, and some rights have legal limits or exceptions. Cloudflare and GitHub have their own processes for requests concerning information they control.

## International transfers

Cloudflare and GitHub operate internationally, so requests or related information may be processed outside your country, including outside the EEA. Their privacy notices describe their transfer arrangements and safeguards. The operator's own server-log storage location depends on the hosting setup.

## Changes

The operator may update this policy when the site's setup or data practices change. The date at the top will change when the policy is updated.
